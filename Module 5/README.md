## About This Lab

This folder contains my solutions for the Module 5 Lab Activity. The assignment focuses on using loops, conditionals, lists, and turtle graphics in Python.

## Files Included

- `problem1_hello_100.py` - Prints "Hello World" 100 times using a loop.
- `problem1_flowchart.drawio` - Flowchart showing the execution of Problem 1.
- `problem2_numbers_and_squares.py` - Prints each number in the given list and then prints each number with its square.
- `problem3_regular_polygon.py` - Asks the user for polygon information and draws a filled regular polygon using turtle.
- `problem4_divisibility.py` - Checks numbers from 1 through 50 and prints whether they are divisible by 3, 5, or both.
- `problem4_flowchart.drawio` - Flowchart showing the execution of Problem 4.
- `problem5_turtle_picture.py` - Uses turtle graphics and loops to draw a flower.
- `TEST_RESULTS.txt` - Notes from testing the programs.

## How to Run the Python Programs

1. Make sure Python is installed on the computer.
2. Open the folder containing the files.
3. Open Command Prompt or Terminal in that folder.
4. Run a program by typing:

```text
py problem1_hello_100.py
```

If `py` does not work, use:

```text
python problem1_hello_100.py
```

Use the same method for the other `.py` files.

## Turtle Programs

Problems 3 and 5 use Python's `turtle` module. When these programs are run, a graphics window should open.

Problem 3 asks the user to enter:

- Length of each side
