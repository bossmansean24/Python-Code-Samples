# Python-Code-Samples
MOD 3 Lab activity
## About This Repository

This repository contains seven introductory Python programs completed for the Module 3 Lab Activity. The programs demonstrate basic Python concepts including output, user input, conditional statements, mathematical calculations, error handling, and the modulo operator.

## Author

Sean Bennett

## Programs

1. `01_hello_world.py` — Prints “Hello World” to the screen.
2. `02_name_greeting.py` — Asks the user for a name and displays a personalized greeting.
3. `03_restricted_greeting.py` — Greets only the student and instructor by name.
4. `04_circle_area.py` — Calculates the area of a circle from a user-entered radius.
5. `05_mpg_calculator.py` — Calculates a vehicle's miles per gallon.
6. `06_fahrenheit_to_celsius.py` — Converts Fahrenheit to Celsius.
7. `07_return_day_calculator.py` — Determines the return day after a specified number of nights.

## How to Run the Programs

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal or command prompt in the repository folder.
4. Run a program with Python. For example:

```bash
python 01_hello_world.py
```

On some Windows computers, this command may also work:

```bash
py 01_hello_world.py
```

Follow the on-screen prompts for programs that request user input.

## Testing

Each program was tested with sample input. The programs that accept numbers include basic checks for invalid input. The MPG program also prevents division by zero, and the return-day program verifies that the starting day is between 0 and 6.
