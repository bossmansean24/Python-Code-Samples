## About This Lab

This lab practices importing and using Python modules. The programs use the
`random` module and the `math` module.

## Files

- `randomrange.py` - Prints 10 random integers from 25 through 35.
- `randomint.py` - Prints a random odd integer between 0 and 100.
- `randomday.py` - Chooses and prints a random day of the week.
- `pi.py` - Compares an arithmetic approximation of pi with `math.pi`.
- `degrees.py` - Converts radians to degrees manually and with `math.degrees`.
- `factorial.py` - Calculates factorial with a loop and compares it with `math.factorial`.
- `TEST_RESULTS.txt` - Shows sample test results.

## How to Run

Open Command Prompt or Terminal in this folder and run a file with:

```text
py randomrange.py
```

If `py` does not work, use:

```text
python randomrange.py
```

`degrees.py` and `factorial.py` will ask you to enter a value.
